# Changelog

All notable user-visible changes to the Resilio Sync TOS application package.

## 3.1.2-1 — 2026-11-12

### Added
- First release. Resilio Sync (`linuxserver/resilio-sync:3.1.2`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8103 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/resiliosyncdocker/`.
